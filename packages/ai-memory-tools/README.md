# @aviaratech/ai-memory-tools

MCP server, ingestion, health, evaluation, and operational CLIs for `@aviaratech/ai-memory`. Build the core package first. Run `npm run mcp -w @aviaratech/ai-memory-tools` for stdio MCP or use the `ai-memory-mcp` bin. Local database configuration is explicit; the source repository includes installation instructions in `docs/installation.md`.
