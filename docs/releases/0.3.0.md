## Changes in 0.3.0

- Curated knowledge retention: `memory_flush` saves continuity checkpoints without creating memories or embeddings. The explicit, backup-gated `ai-memory cleanup` removes historical flush fragments, promoted session summaries and unused history while preserving curated memories, required lineage and contested pairs.
- Migration `010_index_first_search` adds a GIN index on the stored `search_vector`, corrects the author/category index and removes obsolete expression indexes. Stop older processes before administrator initialization. An older package cannot start against the longer migration ledger; rollback requires the matching package and a compatible restored backup.
- Index-first search selects bounded candidates through text, key, tag and reference indexes before ranking the combined pool. This releases the search change from #66 and cleanup from #63; operational latency and retention targets still require measurement on the adopted install.

Follow [Adopting 0.3.0](https://github.com/aviaratech/ai-memory/blob/v0.3.0/docs/operations.md#adopting-030) for registration preservation, pause, backup verification, cleanup, embedding backfill, health checks and recovery. The core npm package and the paired GitHub plugin archive are both version 0.3.0. Publishing this release does not execute the checklist on an operator install.
